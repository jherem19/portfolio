AE Bridge · Beta 0.4.17

Connect the Community plugin

  1. Open AE Bridge in Figma, then click Connect.
  2. Copy the private code below and paste it into Connection code.
  3. Click Connect companion. This pairs the plugin with this computer.

Keep this code private. It authorizes design transfers to your local companion. Each computer has its own code.

Send a selection

Open After Effects, your project and the target composition. Select your Figma layers, choose Editable or Raster image, then click Send to After Effects. Enable Precompose selection to place the imported layers inside one precomp.

Figma placement uses the containing design frame matching the AE composition. Center centers the selection; Origin starts at the top-left. Text and compatible vector shapes remain editable. Gradients currently simplify to solid colors.

Manual fallback

Export .jsx works without pairing. In AE, choose File → Scripts → Run Script File.

Development fallback

Before the Community listing is available, import this manifest in Figma desktop: __MANIFEST_PATH__.

Local processing

Design data goes only to the local companion. PNGs remain under %LOCALAPPDATA%\AEBridge\data\assets so AE can reference them. There is no telemetry or remote design upload. The pairing code is stored in Figma plugin storage on this device.

Windows x64 only. Conversion tested in After Effects 26.5. Beta software; review your import. AE path: __AE_PATH__.
