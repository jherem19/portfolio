AE Bridge Beta 0.4.17 for Windows x64.

Transfers Figma selections into the active After Effects composition as native layers, one precomposition or a raster image. The Community build contains no installation key. Pair it with the Windows companion using the private code generated by First steps. Manual JSX export remains available.

Conversion tested in After Effects 26.5. Gradients currently simplify to solid colors; unsupported effects or geometry may be simplified or rasterized. No automatic synchronization or replacement.
