AE Bridge Beta 0.4.19 for Windows x64.

Adds Raster layers for selected Figma frames. Import frame contents as separate optimized images, choose any nested layer depth, or use the independent All layers option. Layer names, order, position and opacity are preserved, while complex visual groups are safely flattened.

AE Bridge also transfers selections into the active After Effects composition as native layers, one precomposition or a single raster image. The Community build contains no installation key. Pair it with the Windows companion using the private code generated by First steps. Manual JSX export remains available.

Conversion tested in After Effects 26.5. Gradients currently simplify to solid colors; unsupported effects or geometry may be simplified or rasterized. No automatic synchronization or replacement.
